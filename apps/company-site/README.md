# Grasta Domhan company homepage

This is the standalone, dependency-free company homepage for `grastadomhan.com`.
It is intentionally separate from `apps/web`, which remains the Findam product
site and will be served from `findam.grastadomhan.com`.

The page is static. Deploy the contents of this directory as the document root
for the company domain; no Node process or build step is required. Product links
are configured for the planned subdomains in `index.html`.
